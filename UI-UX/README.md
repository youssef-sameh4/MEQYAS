# MEQYAS UI/UX Design

This directory contains the UI/UX design documentation and deliverables for the MEQYAS platform.

## Responsibilities

* User research and user flows
* Wireframes
* High-fidelity UI designs
* Design system
* User experience documentation
* Design handoff documentation for the Flutter developer

## Design Tools

The team may use Figma or other suitable design tools.

## Design Handoff

Final designs should include the required screens, reusable components, typography, colors, and interaction states.
